# Stop-screen puns

Approved lines for the stop screens (D-021). When a screen is built, copy its list into a `string-array` in
`core/resources` (NFR-L3). Edit lines here first, then in the resources.

**Order (F8.13, F16.9):** shuffle bag. Every line is shown once in random order before any repeats, and the
first line of a new round is never the last line of the previous round. The bag position is saved, so it
survives restarts.
